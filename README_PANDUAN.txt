CAT SKB JAKSA AHLI PERTAMA — WEB GRATIS 100%
============================================

ANDA TIDAK PERLU PYTHON, CMD, OPENAI API ATAU MEMBELI HOSTING.

A. COBA LANGSUNG TANPA WEBSITE
1. Ekstrak file ZIP.
2. Klik dua kali BUKA_LANGSUNG_CAT_GRATIS.html.
3. Kerjakan 100 soal di Chrome atau Edge.
4. Dalam mode langsung, paket awal sudah tertanam dalam HTML.

B. TERBITKAN SEBAGAI WEBSITE GRATIS
1. Buka https://github.com dan masuk / daftar akun gratis.
2. Buat repository bernama cat-skb-jaksa, pilih PUBLIC, lalu Create repository.
3. Klik Add file > Upload files; unggah isi paket: index.html, .nojekyll, dan folder banks dengan berkas di dalamnya.
   PENTING: index.html harus berada di akar repository dan banks/index.json beserta banks/starter-20261019.json tetap pada path yang sama.
4. Klik Commit changes.
5. Masuk Settings > Pages. Pada Source pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. GitHub menampilkan URL situs ketika penerbitan selesai. Biasanya berbentuk:
   https://NAMA-PENGGUNA.github.io/cat-skb-jaksa/
   Contoh tersebut bukan tautan aktif milik Anda, alamat aslinya hanya diketahui setelah diterbitkan.

C. FITUR
- 100 soal A–E, 36 indikator, komposisi 82 khusus dan 18 umum.
- Durasi 60,90,100,120,150 menit; navigasi 100 nomor; tandai ragu.
- Jawaban baru terlihat setelah selesai, lengkap dengan pembahasan.
- Simpan otomatis dalam browser peserta; unduh hasil CSV / cetak PDF.
- Paket bank tambahan bisa diterbitkan GRATIS dengan mengunggah JSON valid dan mengedit banks/index.json.

D. BATASAN
- TIDAK menghasilkan 100 soal baru otomatis tiap hari. Penambahan manual oleh pengelola.
- Kunci soal dapat ditemukan dalam kode sumber. Cocok untuk latihan mandiri, bukan ujian resmi berkeamanan tinggi.
- Data peserta tersimpan lokal pada browser masing-masing, tidak dikirim ke server.
- Konten hukum belum diverifikasi ulang oleh ahli, dan kisi-kisi merujuk pengumuman 2024.
- Repository dan website PUBLIC, jangan mengunggah informasi rahasia pribadi atau API key.
- Hosting GitHub Pages pada GitHub Free tersedia untuk repository PUBLIC menurut dokumentasi GitHub saat penyusunan.
